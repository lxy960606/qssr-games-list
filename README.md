# QSSR games list

This list covers eight PS5 games with released or announced support for QSSR, Sony’s AI upscaling technology. Each entry links to a primary source from Sony or the developer. A title is listed as available only when a released update carrying QSSR is documented.

## Available now

These three games have released updates that add QSSR, and a listed patch number identifies the update that introduced it, which may differ from the latest version.

| Game | Patch | Notes | Source |
| --- | --- | --- | --- |
| Marvel's Wolverine | 1.002.000 | QSSR is on by default on PS5. The cited sources do not document a manual switch. | [Insomniac update 1.002.000][wolverine] and [PlayStation Blog, Oct 1 2026][oct] |
| Marvel's Spider-Man 2 | 1.006.000 | QSSR works in both Fidelity and Performance modes. | [Insomniac release notes v1.006.000][spider-man] and [PlayStation Blog, Nov 13 2026][nov] |
| Ghost of Yōtei | Not confirmed | Sony confirmed an update adding QSSR as a graphics option. The cited announcement gives neither a patch number nor a menu path. | [PlayStation Blog, Oct 1 2026][oct] |

## Announced, not released

Developers have announced QSSR for these five games, but this list has not verified a released update for any of them, and any stated window describes a plan rather than a confirmed release date.

| Game | Patch | Source |
| --- | --- | --- |
| ARC Raiders | Not confirmed | [PlayStation Blog, Nov 13 2026][nov] |
| Control Resonant | Not confirmed | [PlayStation Blog, Nov 13 2026][nov] |
| THE FINALS | Not confirmed | [PlayStation Blog, Nov 13 2026][nov] |
| No Man's Sky | Not confirmed | [PlayStation Blog, Nov 13 2026][nov] |
| Hell Let Loose: Vietnam | Not confirmed | [PlayStation Blog, Nov 13 2026][nov] |

QSSR support is documented per game. The cited sources do not document a console-wide switch or an available QSSR setting for any game in the announced group. Games that only media outlets have predicted are deliberately left out until Sony or the developer confirms them.

Last re-checked against both Sony posts and the Insomniac release notes on 2026-11-24. This list changes when Sony or a developer publishes something new; between announcements the dates stay the same.

Per-title details, including confirmed patch numbers and official sources, are maintained at <https://qssrgames.app/games/>.
